Question & approach

Question. Does the baseline single-cell→division sim reproduce wild-type E. coli properties across a multiseed/multigen ensemble? The wild-type baseline resumed from the showcase-1 full ParCa cache should produce a doubling time in band, physiological mass fractions, FBA fluxes that correlate with Toya 2010, and a proteome that correlates with Schmidt 2016 / Wisniewski.
Summary. The wild-type baseline is the unperturbed v2ecoli whole cell growing in glucose minimal medium. Reproducing the four measured-property classes — doubling time, biomass composition (mass fractions), central-carbon flux (vs Toya 2010), and the proteome (vs Schmidt 2016 / Wisniewski 2014) — across a multiseed/multigen ensemble is the evidence that the cell is "the same E. coli" the upstream WCM was validated against, and the reference that all showcase-4 perturbation variants are measured against.

✓ Resolved uncertainties

  • The central-carbon FBA-vs-Toya-2010 scatter is regenerated on the clean run — the Toya 2010 flux validation TSV (toya_2010_central_carbon_fluxes.tsv) was restored to v2ecoli/validation/ecoli/flat/ and build_validation_data now exposes validation_data.reactionFlux.toya2010fluxes. The baseline FBA fluxes correlate with the Toya 2010 C13-MFA measured fluxes at Pearson R = 0.6990 (p = 2.1e-4, n = 23 reactions).
  • The wild-type baseline reproduces the measured-property classes on the clean 3-generation re-run (doubling time in-band, physiological mass fractions, Schmidt r≈0.73 / Wisniewski r≈0.60) — no calibration trade-off appeared across them.
  • RESOLVED (was: gen-2 doubling-time step-cap over-report): #173 ends each non-final generation at its real division, so gen-2 now reads 43–52 min (in-band) instead of the old ~104 min cap-inflated value. The doubling_time_line / doubling_time_hist figures show a clean gen-2.
  • RESOLVED (reviewer: 'why is the doubling time going down? get more samples'): the apparent decline was the cap-truncated FINAL generation, not a real trend. doubling_time_line / doubling_time_hist now lead with a cap-immune instantaneous doubling-time trace t2 = ln(2)/mu from listeners.mass.instantaneous_growth_rate over the whole lineage (218 per-timestep samples vs the old 3 generational points): STABLE at ~44–52 min (mean ~52 min), no decline. Per-generation division-time markers are kept but the truncated final generation is excluded so it no longer reads as a downward trend.
  • RESOLVED (was: gen-3 mislabeled / folded phylogeny): the clean re-run has the correct lineage labelling — gen1 agent=0 / gen2 agent=00 / gen3 agent=000 for both seeds — so cell_mass now renders three distinct clean generations.

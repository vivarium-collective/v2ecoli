🔬 Interactive model viewer

  • Composite viewers hub — every curated composite (baseline, biological, Millard FBA bridge, colony, reactor–bird coupling) as an interactive bigraph: open each in bigraph-loom (pan/zoom, expand store chips, inspect port schemas with units and formal process descriptions), bigraph-viz2 (lightweight interactive), or a static bigraph-viz diagram.
  • Mathematical structure — the formal mathematical structure of each process (state variables and update rules), e.g. chromosome replication initiate/elongate/terminate.

Engine comparison

  • Composite comparison — the default engine comparison. Thorough multi-engine run of vEcoli, the v2ecoli baseline, and the millard_fba_bridge_harness over a full division cycle: per-step runtime (mean/median/p95 + peak RSS), divergence-verdict badges and shared-axis behavioral overlays for every observable, FBA-bridge flux-pin diagnostics, and a per-reaction flux divergence deep-dive (which metabolic pathways carry different flux between engines).
  • vEcoli vs v2ecoli (legacy 2-way) — the older fixed two-engine report: wall-time benchmarks and mass/growth trajectories. Superseded by the Composite comparison above.

ParCa

  • ParCa workflow report — merged nine-Step ParCa pipeline run. Per-step runtimes, port manifests, raw-data (flat TSV) stats, and distribution overlays vs vEcoli reference where intermediates are available.
  • ecoli-sources bundle — ParCa input data sources pulled from the ecoli-sources package (reconstruction flat files); real ParCa output plus a multi-ParCa demo (operons on/off).

# vEcoli ↔ v2ecoli — growth-condition equivalence

Statistical-equivalence report cards comparing the **vEcoli** (Vivarium 1.0)
reference against the **v2ecoli** (process-bigraph) port, run across three
nutrient/growth contexts. Each engine uses a prebuilt, cached ParCa sim_data
(no re-fit); vEcoli applies the condition from its config at runtime, v2ecoli
uses a per-condition cache built from `models/parca/parca_state.pkl.gz` via
`save_sim_input(condition=…, fixed_media=…)`.

Generated by the config-driven comparison harness
(`scripts/compare_harness.py`); see PR vivarium-collective/v2ecoli#271.

## Reading

- **`index.html`** — the full self-contained comparison report (all three
  contexts as navigable run-groups: loaded config, converted processes,
  ParCa/sim_data, sim dynamics, time-axis behavior overlays, report card).
- **`<context>/report_card_verdict.json`** — the machine-readable
  `report_card_verdict/v1` verdict per context (the same schema the
  `report_card_axis` study evaluator consumes, if later wired into a study).

## Takeaway

The two implementations agree in **basal** but **diverge in richer (with_aa)
and anaerobic (no_oxygen)** media — v2ecoli grows ~21% faster than vEcoli with
amino acids, and both mass and growth diverge ~12–14% anaerobically. Whether
this is a genuine implementation difference or a per-condition calibration
nuance is a concrete follow-up.

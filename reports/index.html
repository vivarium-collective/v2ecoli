duf-final-report ✓ 315 KB Open ↗
workspace/references/expert/duf_final_report_2026.pdf

DARPA DUF ARC final report (HR0011-24-3-0372, UConn, PI Agmon, Sep 2024–Sep 2025): "An Integrated Discovery Workflow for an E. coli Whole-Cell Model". Establishes the motivation for the PDMP reformulation of v2ecoli — the current hybrid-algorithmic WCM is not a well-defined dynamical system and resists likelihood-based inference and causal discovery.

Contributor: eran

v2ecoli-pdmp-roadmap ✓ 11 KB Open ↗
workspace/references/expert/v2ecoli_pdmp_roadmap.pdf

Six-phase incremental roadmap for transforming v2ecoli into a piecewise-deterministic Markov process (PDMP). Phases 0–5: characterization → kinetic-ODE metabolism → continuous-time jump layer → likelihood/Bayesian interface → compiled runtime → causal discovery / functional annotation. Spine of the v2ecoli-pdmp investigation.

Contributor: eran

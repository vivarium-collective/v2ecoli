Claim

Can v2ecoli (with the mbp-01 time-varying-env hook and mbp-02 population aggregator) be coupled to `pbg-bioreactordesign`'s BiRDReactorProcess — via a thin adapter that resolves the biomass-ownership conflict between the two — such that BiRD supplies dissolved O2, kLa, gas-phase physics, and v2ecoli supplies population biomass and exchange-flux demand, producing a physically consistent coupled trajectory in a 0D well-mixed bench-scale reactor?

Four-way coupling: (1) population biomass -> reactor.biomass; (2) dissolved O2/CO2 (mg/L->mM) -> v2ecoli environment; (3) aggregated metabolism O2 uptake -> BiRD O2 demand; (4) metabolism CO2 production -> BiRD CO2 demand. Expected biology: DO drops below Henry saturation as cells consume O2; dissolved CO2 rises above saturation; higher kLa raises DO and strips CO2; no-cells runs reach Henry equilibrium.

req-2-cell-coupler — ReactorCellCoupler Step M [process]

PBG Step running each emit cycle. Reads: - `population.biomass_concentration_gL` → writes `reactor.biomass` (BiRD biomass input) - `reactor.dissolved_o2`, `reactor.dissolved_co2` (mg/L) → converts to mM and writes `environment.external_concentrations.{OXYGEN-MOLECULE[p],CARBON-DIOXIDE[p]}` - aggregated `agents.*.metabolism.external_exchange_fluxes.OXYGEN-MOLECULE[p]` × population.total_biomass_gDW → writes `reactor.o2_uptake_rate` (BiRD input) Holds last-known reactor state between BiRD ticks (BiRD typically on 1 h interval).

Unblocks: all mbp-03 behavior_tests

req-3-reactor-bird-composite — v2ecoli.composites.reactor_bird_coupled S [composite]

Composite combining v2ecoli.composites.ecoli_population + baseline_time_varying_env + BiRDTransportProcess + ReactorCellCoupler. No "disable internal biomass" step required — BiRDTransportProcess has no biomass ODE by construction.

Plan & assumptions

Pipeline gate

Each study is a model-building gate: it answers "Can we safely build the next layer?"

Prerequisites: none (root study)
Proceed when: Coupling direction tests pass (DO drops with cells, dissolved CO2 rises with cells, higher kLa lifts DO and lowers dissolved CO2); no-cells runs reach Henry equilibrium for both O2 and CO2; one v2ecoli generation completes without state divergence; O2 mass-balance test closes (previously referenced by the gate but not actually implemented in the test set — chris_feedback_2026_05_26 §7 consistency fix).

Key assumptions

  • 0D well-mixed reactor; bubble column geometry as the default for mbp-03 (per BiRD's default). Stirred-tank may be required for mbp-05 Beulig matching — see open_question reactor-geometry-for-beulig.
  • BiRDTransportProcess (Option-B fork) has no internal biomass ODE; v2ecoli's population is the SOLE source of biomass truth — by construction, not by flag.
  • v2ecoli's per-cell μ from metabolism — when aggregated by cells_per_agent — captures the same physics BiRD's Monod would have approximated.
  • Timestep: sim duration 240 min (4 BiRD ticks at 1-h default) chosen so 'second-half steady-state' windows are meaningful. If BiRD's interval is tunable in the fork (open_question coupler-timestep-tunability), drop to ~minutes and tighten tolerances.

Limitations

What this study explicitly does NOT validate (prevents overclaim).

  • Uses BiRDTransportProcess from the upstream `pbg-bioreactor-transport-fork` PR — until that lands and is pinned, mbp-03 cannot enter Build phase.
  • Single v2ecoli generation only (or, in chris_feedback_2026_05_26 §6 terms, 4 BiRD ticks); multi-generation stability is mbp-04's scope.
  • Bubble column geometry default; stirred tank / airlift not validated this phase. May need switch for Beulig matching (open_question reactor-geometry-for-beulig).
  • Fed-batch operations not supported (pbg-bioreactordesign has no fed-batch yet) — flagged as a deferred enhancement; mbp-05 may stress this.
  • Coupler timestep mismatch (BiRD ~1 h default, v2ecoli ~1 s): the coupler holds last-known BiRD state between BiRD ticks. Mitigated to acceptable by 240-min default sim duration (4 ticks). Open_question coupler-timestep-tunability tracks the path to BiRD-interval-as-tunable in the upstream fork.

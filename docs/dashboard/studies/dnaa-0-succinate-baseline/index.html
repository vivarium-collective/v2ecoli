Purpose
Question. Does v2ecoli, under the ParCa-default succinate growth condition with no imposed τ / C / D overrides, reach a per-cell periodic steady state in a single_daughters lineage — oriC count oscillating 1 ↔ 2 at steady state (gen 3 onwards), with cell mass periodic in phase? A transient overshoot to 4 in the first generations is allowed and expected (it marks the pre-steady-state relaxation; Rashmi 2026-05-30). If yes, save the gen-3 state as the canonical succinate steady-state initial condition for subsequent studies in this investigation.

Key assumptions
  • Succinate is the right baseline media. ParCa default τ ≈ 82 min and C + D = 60 min give B = 22 min > 0, satisfying Rashmi's non-overlapping cycle requirement (replication initiates exactly once per generation).
  • v2ecoli is configured for succinate out of the box (saved sim_data state). No new ParCa rebuild from raw inputs is required — just run ParCa with succinate as the growth condition.
  • single_daughters=True is the correct mode for steady-state checking. Tracks ONE daughter per division through the full 10-gen lineage so per-cell observables can be compared cycle-to-cycle.

Discovery implications

Where this study's results leave the mechanism model — and what to investigate next.

✓ Resolved uncertainties

  • Under ParCa-default succinate with no τ/C/D overrides, the single-daughters lineage reaches a periodic steady state by generation 3 (oriC 1↔2, cell-mass sawtooth CV ≤ 4.5%) — establishing a valid baseline cell cycle for the DnaA studies.
  • The gen-1–2 oriC overshoot to 4 is the expected pre-steady-state relaxation (reviewer-confirmed), not a defect; gen 3 is the correct burned-in state to save as the canonical initial condition.
  • The unregulated baseline DnaA monomer pool sits far below the literature [300,800] band (per-gen mean declining 44→4), quantifying the calibration gap dnaa-1 must close.

● Remaining uncertainties

  • Whether the gen-1–2 transient overshoot to 4 oriC is purely an initial-condition artefact or has any seed/parameter sensitivity — only seed 0 was run, and the 5-gen lineage was accepted in place of the spec's 10 generations.
  • How robust the periodic 1↔2 steady state is to seed variation, since the canonical run is a single seed.

Alternate hypotheses (1)

The gen-1–2 oriC overshoot to 4 (and the short gen-2 τ of 52 min) is an artefact of the resume-from-gen-1 daughter initial condition, not an intrinsic property of the succinate attractor.
The overshoot appears only in the first generations and disappears from gen 3 onward; gen 2 also has the shortest τ, both consistent with a state not yet aligned with the periodic attractor.

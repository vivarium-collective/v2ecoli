A minimal, self-contained demonstration of the two lightweight perturbation levers built directly into the `baseline` composite. Both reuse the existing ParCa cache — no re-fit — so each perturbation is a one-line variant:

- `knockouts`: translation-level gene knockouts. Each named gene's translation efficiency is zeroed on the cached polypeptide-initiation config, so no protein is made — a functional knockout with no ParCa re-fit. (Folded in from the former KO_baseline composite.) - `media`: an in-cache media shift. The environment's initial media_id is set to any condition in the cache's saved_media, so the media_update step moves the cell onto that condition on the first tick and metabolism responds (e.g. amino-acid-rich media grows faster).

The single study `ko-and-media` runs the wild-type baseline against a lacY knockout and an amino-acid-rich medium, side by side. This is a starting point / how-to for perturbing the whole cell — not a rigorous result. For a rigorously-calibrated media condition, run a per-condition ParCa cache instead (see the v2ecoli-vecoli-comparison investigation's succinate study).

The v2ecoli baseline is a wild-type E. coli cell; a perturbation asks how that cell responds when one thing changes. This demo uses two minimal, biologically distinct levers.

A translation-level gene knockout zeroes the translation efficiency of a named gene on the cached polypeptide-initiation config, so its mRNA is still transcribed but no protein is synthesized -- the phenotype of a loss-of-function mutant without re-fitting the model. lacY, the lactose permease, is a convenient demo target: knocking it out removes a membrane transporter with little cost on glucose medium.

A media shift instead changes the environment the same genome sees: supplementing the minimal medium with amino acids relieves the cell of synthesizing them de novo, which lowers ppGpp, up-regulates ribosome synthesis, and speeds growth. Both levers reuse the existing ParCa cache -- no parameter re-fit -- so each perturbation is a one-line variant on the baseline, making them ideal for showing how genotype and environment separately move a whole-cell phenotype.

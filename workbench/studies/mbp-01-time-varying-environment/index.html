Claim

Can v2ecoli's `media_update` / `exchange_data` Layer-1 Steps consume an externally-driven, time-varying nutrient pool — instead of the static media configuration baked into ParCa — such that metabolic exchange fluxes and growth rate respond correctly to declining glucose, declining DO, and other dynamic external concentrations?

PLUMBING-ONLY (per chris_feedback_2026_05_26 §3): verifies the wire under extreme/saturating inputs robust to v2ecoli's internal transport-kinetics functional form (saturable MM / constant-bound / linear). Biological floors checked: zero external substrate -> zero exchange flux; uptake at 50 g/L respects the published E. coli glucose-PTS Vmax (~10-12 mmol/gDW/h); uptake plateaus across 5 vs 50 g/L (saturable kinetics). Gradient-shape / mu-vs-[glucose] fidelity is deferred.

Test

Model mbp-01-time-varying-environment
Measures An external_glucose store update is reflected in metabolism's GLC[p] exchange constraint within one timestep. Direct wire check — replaces the removed `uptake-flux-tracks-external-glucose` Pearson test (which assumed linear response between concentration and uptake; v2ecoli's PTS is saturable).·Closed-balance cumulative mass conservation (MassConservationDeriver) — the relative cumulative residual between cell-mass change and net environmental exchange stays near zero, confirming the environment hook is wired without leakage.·With env_driver_mode=static, the composite produces the same baseline trajectory (e.g. DnaA count, growth rate) as the unmodified v2ecoli.composites.ecoli_baseline. Regression guard.·external_glucose held at 0 → glucose exchange flux ≈ 0 (numerical tolerance). Same for DO: zero external DO → O2 exchange flux ≈ 0. Universal biological floor; also confirms plumbing.·external_glucose held at 50 g/L (~30,000× PTS Km) → glucose exchange flux ≤ published Vmax for E. coli glucose-PTS (~10–12 mmol/gDW/h). Catches the unphysical linear-scaling implementation case.·Two runs at 5 g/L and 50 g/L (both far above PTS Km) → GUR within a tight ratio tolerance. Both above Km, so saturable and constant-bound models predict matching GUR; linear scaling would predict ~10× difference. Direct discriminator between physical and unphysical implementations.

Model change

Base model: v2ecoli.composites.ecoli_baseline

New processes:

  • EnvironmentDriver (Step · req: req-1-env-driver)

New state variables:

  • environment.external_concentrations (map[float], mM) — populated by external physics each timestep

New parameters:

  • env_driver_mode = external_store ({static|external_store|synthetic_trajectory})
  • env_driver_trajectory_spec = None (—)

Modified processes:

  • media_update / exchange_data: read external_concentrations (when env_driver_mode != static) instead of static media config. Backward-compatible default.

Internal v2ecoli enhancement — the smallest viable hook that lets external physics drive v2ecoli's metabolism. Implementation must keep the static-medium path untouched for existing baseline regressions (verified by the static-env-regression sim above).

Implementation requirements (2 items)

Concrete pieces of work that gate this study from Design → Build. Each generates a task.

req-1-env-driver — EnvironmentDriver Step S [process]

PBG Step that, each timestep, writes to environment.external_concentrations from either (a) an external source store (default for reactor coupling), or (b) a synthetic trajectory function (for unit testing this phase). Hooks the existing media_update to read from this store when env_driver_mode != static.

Unblocks: linear-glucose-decline · zero-substrate-clamp · saturating-glucose-low · saturating-glucose-high · all primary tests

req-2-time-varying-composite — v2ecoli.composites.ecoli_time_varying_env XS [composite]

Thin wrapper around v2ecoli.composites.ecoli_baseline that injects EnvironmentDriver and the environment.external_concentrations store. Backward-compatible default: env_driver_mode=static.

Unblocks: all mbp-01 simulations

Plan & assumptions

Pipeline gate

Each study is a model-building gate: it answers "Can we safely build the next layer?"

Prerequisites: none (root study)
Proceed when: All plumbing tests pass (external_glucose_updates_propagate_within_one_step; cumulative-mass-balance-closes; static-env-baseline-unchanged) AND all qualitative-extreme tests pass (zero-substrate-blocks-uptake; saturating-substrate-respects-vmax; plateau-across-saturating-range). Gradient-shape / quantitative-biology tests are explicitly OUT of scope (deferred to `transport-kinetics-fidelity` candidate-future-study).

Key assumptions

  • v2ecoli's metabolism Process can re-read environment constraints every step (it already does via `exchange_data_from_media`).
  • External concentrations are well-mixed (single value per species across all agents in this single-cell study).
  • No timestep mismatch handled this phase — env updates and metabolism updates run on the same timebase.

Limitations

What this study explicitly does NOT validate (prevents overclaim).

  • PLUMBING-ONLY scope (per chris_feedback_2026_05_26 §3). Gradient-shape and quantitative-biological-fidelity tests (e.g. μ response to glucose decline near Km, acetate flux shift at sub-Vmax DO, GUR-vs-[glucose] curve) are deferred to a `transport-kinetics-fidelity` candidate-future-study under mbp-06 axis A.
  • REMOVED tests with rationale (kept here so future agents don't re-add them by reflex): `uptake-flux-tracks-external-glucose` (Pearson ≥ 0.7 assumed linear response; real PTS is saturable, ~3 orders of magnitude above the sweep range — test fails on every realistic implementation). `low-do-clamp-reduces-o2-uptake` (5 µM DO clamp is 25-200× above cytochrome bd/bo3 Km, so OUR shouldn't reduce at this clamp; Vemuri 2006 supports acetate-RISE under low DO, not OUR-drop — citation/test mismatch). `mu-drops-when-glucose-depletes` (kinetics-dependent; defer to transport-kinetics-fidelity study).
  • Single cell only; population aggregation is mbp-02's job.
  • Reactor physics (kLa, gas transport) not coupled here — that is mbp-03.
  • Time-varying-medium support assumes the same exchange-molecule set as static medium; new species require ParCa regeneration.

Purpose

Question. Configured with operating conditions matched to the 2025 Palsson lab high-density E. coli study, does the v2ecoli ↔ pbg-bioreactordesign coupled model **render a structured comparison report** (sim-vs- published overlays + categorized divergences + open questions) on the published WT batch-phase prefix trajectories, suitable to feed mbp-06's gap-analysis synthesis? Investigation-level note: the original question framing ("match within tolerance") was reframed 2026-05-26 to "render a structured comparison." The success definition is whether the comparison was EXECUTED AND REPORTED COHERENTLY, not whether biology matched. All biological divergences feed mbp-06 unchanged.
Mechanism / Model change. The benchmark paper is Beulig et al. 2025 (mSystems 10(7), doi:10.1128/msystems.00323-25; senior author B. Palsson), titled "Trade-off between resistance and persistence in high cell density cultures." Open access, PDF at `references/papers/Beulig_2025_mSystems_high_cell_density.pdf`; extracted metadata + scope notes at `references/expert/palsson_2025_fed_batch.md`. Digitized trajectories at `references/papers/palsson-2025-supp/`. Two-stage batch → fed-batch fermentation to 50–80 gDW/L in parallel well-controlled bioreactors; exponential feeding after batch-to-fed- batch transition (t=0 h); >470 transcriptomic samples across five strain groups (WT BW25113, 31 SGKO, TRP, TRPp, MEL) and four fermentation phases (I–IV). For mbp-05, scope is WT only and (until fed-batch lands in pbg-bioreactordesign) the BATCH PHASE PREFIX. Configure the mbp-03/04 coupled composite to the published operating profile (reactor geometry, aeration, medium, initial conditions). Run; render comparison overlays for every sim ↔ published trajectory pair listed in `comparison_overlays` below (~8 surfaces); categorize divergences in the report card across four categories (v2ecoli metabolic deficiency / coupling-adapter limitation / experimental uncertainty / placeholder-induced). **No new model capability.** model_change is empty. The comparison harness (`req-2-comparison-harness`) is generic over the `comparison_overlays` config — adding a new comparison = adding one YAML entry. Future investigations reuse the harness with their own list. Transcriptional-state matching against the >470 transcriptomes is a natural extension (v2ecoli outputs transcript counts) — out of mbp-05 scope; pre-seeded as mbp-09 candidate-future-study in mbp-06.
Expected outcome. For each entry in `comparison_overlays`, the harness produces a single overlay panel + derived comparison metrics. The deliverable is the report card: a markdown document with all overlay panels and a structured `## Divergence triage` section enumerating divergences against the four-category taxonomy, each pointing at the specific sim path / published column / observation that drove the categorization. Pass / fail of each test below is about whether the overlay+triage artifact was produced — not whether biology matched. Divergences are valuable: each one is a specific mbp-06 gap finding seed.

Limitations

What this study explicitly does NOT validate (prevents overclaim).

  • EVALUATION PHASE (chris_feedback_2026_05_26 §10): mbp-05 deliberately does NOT make tolerance-based biology claims. The original framing (`end-of-run-od-matches-published` etc.) structurally encoded an open-ended menu of model knobs to turn — even with the 'no silent tuning' discipline, the impulse to tune to a tolerance-test was built into the test design. The reframe shifts the bound on the AI agent to 'execute and report'.
  • Single benchmark study; not a multi-dataset validation.
  • Fed-batch operations remain a deferred enhancement (pbg-bioreactordesign has no fed-batch yet); this study scopes to the BATCH-PHASE PREFIX of the Beulig dataset.
  • v2ecoli's calibration is slow-growth M9-glucose (~60-min doubling, single cell); the high-density 50–80 gDW/L regime is OUTSIDE the calibration envelope. Under the new framing this is no longer a 'tolerance must reflect this' caveat — it becomes one of the divergences mbp-06's gap analysis categorizes.
  • Strain scope: WT BW25113 only. SGKO (31 knockouts) / TRP / TRPp / MEL are deferred — natural candidate-future-studies under v2ecoli's variant scope.
  • Transcriptional-state matching against >470 Beulig transcriptomes is a unique benchmark axis (v2ecoli has transcripts; upstream dFBA path does not) — deferred to mbp-09 (pre-seeded in mbp-06).

req-2-comparison-harness — Generic sim-vs-published comparison harness S [tooling]

Iterates over the study's `comparison_overlays` list, for each entry: - Resolves `sim_path` against the run output (handles `aggregation: per_biomass` and any other reductions). - Loads `published_csv` and extracts `published_column`. - Renders an overlay panel (sim trajectory + published trajectory, time-aligned) → report/overlay_<name>.png - Computes per-overlay derived metrics (end-of-run value diff, shape-similarity, peak timing, etc. — keyed by the panel's `backs_tests`). - Categorizes any large divergences into the four-axis taxonomy in report/divergence_triage.md (with evidence pointer to the panel + sim_path + published_column).

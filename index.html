v2ecoli → PDMP Whole-Cell Model Reformulation in progress

A six-phase investigation that incrementally transforms v2ecoli from a hybrid algorithmic WCM into a piecewise-deterministic Markov process. Each phase replaces one component of the WCM (metabolism, stochastics, likelihoods, runtime, inference layer) while leaving the rest intact.

🔬 Interactive model viewer

  • Baseline composite — the whole-cell model as an interactive bigraph: pan/zoom, expand store chips, toggle nodes, and click a process to inspect its input/output port schemas (with units) and formal mathematical description.
  • ParCa pipeline — the nine-Step parameter-calculator composite, same interactive view.
  • Baseline state viewer — single-page app browsing the full baseline simulation state.
  • Mathematical structure — the formal mathematical structure of each process (state variables and update rules), e.g. chromosome replication initiate/elongate/terminate.

Engine comparison

  • Composite comparison — the default engine comparison. Thorough multi-engine run of vEcoli, the v2ecoli baseline, and the millard_fba_bridge_harness over a full division cycle: per-step runtime (mean/median/p95 + peak RSS), divergence-verdict badges and shared-axis behavioral overlays for every observable, FBA-bridge flux-pin diagnostics, and a per-reaction flux divergence deep-dive (which metabolic pathways carry different flux between engines).
  • vEcoli vs v2ecoli (legacy 2-way) — the older fixed two-engine report: wall-time benchmarks and mass/growth trajectories. Superseded by the Composite comparison above.

ParCa

  • ParCa workflow report — merged nine-Step ParCa pipeline run. Per-step runtimes, port manifests, raw-data (flat TSV) stats, and distribution overlays vs vEcoli reference where intermediates are available.
  • ecoli-sources bundle — ParCa input data sources pulled from the ecoli-sources package (reconstruction flat files); real ParCa output plus a multi-ParCa demo (operons on/off).

Cell lifecycle

  • Workflow report — full single-cell lifecycle: mother grown to division, then both daughters run for half a generation. Mass, growth, ppGpp, chromosome state, and process-bigraph network view.
  • Multigeneration report — single-lineage simulation across a configurable number of generations. Each cell runs to division, one daughter is kept, and the process repeats. Mass trajectories plotted end-to-end with generation boundaries.

Colony simulation

  • Colony report — one whole-cell E. coli embedded in a 2D colony of adder-kinetics surrogates, with synced colony and chromosome animations.

Composition graphs

  • Baseline (partitioned) — the current single-cell baseline model.
  • ParCa pipeline — upstream 9-Step ParCa composite that produces sim_data.

Reports are generated by scripts in the reports/ directory: v1_v2_report.py, colony_report.py, workflow_report.py, multigeneration_report.py, and network_report.py. Source: vivarium-collective/v2ecoli.

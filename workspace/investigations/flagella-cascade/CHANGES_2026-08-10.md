# Flagella-cascade investigation — changes, 2026-08-10

Two threads today: (1) scaffolded and validated a standalone reduced ODE
model as an alternative to the WCM-embedded diagnostics, and (2) removed
the FliT:FlhD4C2 checkpoint mechanism entirely after a literature check
found it likely doesn't operate significantly in E. coli K-12.

---

## 1. Reduced ODE model (`flagella-06-reduced-ode-model`)

Built a standalone system of ODEs (scipy, no process-bigraph composite, no
ParCa cache, no division/metabolism/FBA) to test the self-limiting-dynamics
question directly, sidestepping the three WCM infrastructure blockers
`flagella-02` hit repeatedly (fliC supply, motor-complex supply, the
division/mass-homeostasis bug).

First run (v1) blew up almost immediately — traced to two real bugs, not
one: the "reference" calibration point was mis-attributed as a late-
timepoint snapshot when it's actually the real natural (un-overridden)
ParCa basal t=0 state, and the FliA:FlgM sequestration term was fit to a
mismatched transient that blew up at the real reference scale. Fixing this
required measuring two binding K_D values directly from the running WCM
(K_D(FlgM:FliA)=144.5, K_D(FliT:FliD)=141.3 count-units — consistent with
each other, as expected since both reactions share the same tabulated rate
constants) rather than deriving them from an uncertain cell-volume
conversion. Also found and fixed a real mechanism gap (the checkpoint's
FliT input needs to be FliT:FliD-equilibrium-corrected, not the raw total
— validated with zero fitting against real data) and a real formula bug
(FlgM secretion is a flat per-flagellum rate, not proportional to
available FlgM).

**Validated v2 result** (matched against real WCM data to within ~2-3x):
over 8 simulated hours, the checkpoint clearly suppresses FlhD4C2 and
drives the expected FliA/FlgM dynamics, but flagella count is NOT bounded
— it grows to 46.5, tracking `nucleation_rate*time` almost exactly. This
independently confirms, via a completely different modeling approach, what
`flagella-02`'s WCM diagnostics already found: the checkpoint regulates
expression correctly but doesn't by itself limit flagella count.

Full detail: `studies/flagella-06-reduced-ode-model/study.yaml`.

## 2. FliT:FlhD4C2 checkpoint removed

**Why:** asked to double-check the FliT:FlhDC checkpoint mechanism in the
literature and look for other on/off signals. The mechanism is real and
biochemically confirmed — in *Salmonella* (Yamamoto & Kutsukake 2006,
*J Bacteriol* 188:5124: FliT binds FlhC, blocks class-2 promoter
occupancy — a DNA-binding-inhibition mechanism, not protein degradation,
a nuance the WCM's Step only approximated). But Albanna et al. (2018,
*Sci Rep* 8:16705) directly tested a Δ*fliT* mutant in **E. coli MG1655 —
this WCM's exact K-12 reference strain** — side-by-side with *S.*
Typhimurium LT2, and found no significant phenotypic effect in E. coli,
versus a clear effect in Salmonella. Given that direct negative result in
the relevant organism, the decision was made to remove the mechanism
rather than keep investing in it, and move toward representing FliT via an
NFsim rule instead — arguably a better mechanistic fit anyway, since
competitive DNA-binding inhibition is naturally a rule-based/site-
competition problem, not a continuous decay term.

**What was removed** (confirmed via direct code check to be the *only*
active regulatory shutdown mechanism on FlhD4C2 in this codebase — flhDC's
own promoter isn't touched by any custom flagella Step):

- `flagella_flit_flhdc_checkpoint.py` (`ecoli-flit-flhdc-checkpoint`) —
  the FliT-mediated regulatory mechanism itself.
- `flagella_flhdc_degradation.py` (`ecoli-flhdc-degradation`) — basal
  ClpXP turnover of FlhD4C2. **Important distinction**: this is *not*
  FliT-specific — it's the only degradation pathway FlhD4C2 has at all
  (the standard `protein_degradation` process only handles monomers,
  never assembled complexes). Flagged this explicitly before removing;
  the explicit decision was to remove both, accepting that this reopens
  the original flagella-count-unbounded-runaway risk until the NFsim
  replacement is built.
- `FLIT-FLID-CPLX_RXN` (`equilibrium_reactions.tsv` /
  `equilibrium_reaction_rates.tsv`) — the FliT:FliD binding equilibrium
  that fed the checkpoint's free-FliT signal.

**Kept**: `FLIT-DIMER_RXN` (FliT homodimer formation) — real,
FliT-regulation-independent biology, left in place as a building block for
the planned NFsim work.

**Archived, not deleted**: all removed code, exact reaction-network
entries, and config wiring are preserved at
`archive/flit-flhdc-regulation-2026-08/` (repo root), with a README
covering the full mechanism, citations, and reasoning — a clean
before/after reference.

**ParCa/sim_data**: rebuilt into a new versioned cache
(`out/sim_data_full_flit_v5` / `out/cache_full_flit_v5`) rather than
overwriting `v4`, so the old FliT-inclusive cache stays available for
comparison.

**Documentation**: `flagella-02-transcription-regulation/study.yaml` and
`flagella-06-reduced-ode-model/study.yaml` both got new findings/
open_decisions documenting the removal — prior historical findings were
*not* rewritten (they remain accurate records of what was tested while the
mechanism was active). `investigation.yaml`'s open_decisions also updated
with the cross-study migration plan.

**Known tradeoff, not an oversight**: any WCM run with `flagella_regulation`
enabled now has no FlhD4C2 shutdown mechanism at all until the NFsim
replacement is built.

Full detail and citations: `archive/flit-flhdc-regulation-2026-08/README.md`.

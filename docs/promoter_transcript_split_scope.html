Separating promoters from transcripts

A design scope for decoupling the promoter — initiation site, TF binding, TSS — from the transcript — RNA species, abundance, decay, length, mass. Today they are one object, the transcription unit, and rna_data is keyed by TU id.

1 · Why

The identifiability argument

The data ParCa fits has a fixed resolution structure.

QuantitySourceResolution
InitiationThomason 2015 dRNA-seq TSS step heightsPer promoter
AbundanceRSEM RNA-seq TPMPer gene
Decayrna_half_lives / cistron half-life tablesPer gene / transcript

Only initiation is promoter-resolved. Modelling N transcript species per operon therefore creates state variables that no measurement can constrain, and ParCa is forced to invent them.

That is not hypothetical. Measured on the shipped fixture, every TU the dedup exemption resurrects receives a fallback:

GroupKept TU deg_rateResurrected TUsFallback half-life
rpsU-dnaG-rpoD0.00723 (1.6 min)0.0001388.9 min
serA0.006240.0001388.9 min

leuLABCD0.004840.0001388.9 min

Km_endoRNase inherits the same corruption — kept ~5e-05, resurrected 2.5616e-03, a 50× weaker affinity. The cause is the NNLS at transcription.py:810, degenerate for TUs of identical cistron composition, which pins the unsolvable ones at min_deg_rates: the global minimum mRNA rate.

The circularity in the current workaround

per_promoter_ratios.tsv uses TSS step heights — initiation data — to apportion abundance across TU species. That substitution is valid only if the variants decay identically. But the group's TUs also share an exact 3′ end, so if they additionally decay identically they are indistinguishable by any quantity in the model. The workaround must assume precisely the premise that makes its own extra species redundant.

2 · What changes conceptually

Dedup stays. One transcript per gene tuple is what the abundance and decay data support, so collapsing TUs is correct. The original defect was never that dedup merged transcripts — it is that dedup discarded promoter identity on the way.

Not lossy for elongation. RNA_ARRAY already carries transcript_length per molecule and RNAPs carry coordinates, so nascent length is a property of the initiation event. It actually improves fidelity: today the nascent RNA starts at replication_coordinate[TU] (transcript_initiation.py:567); under the split it starts at the promoter's own TSS, which is the real one.

6 · Scale

3766 TU rows in transcription_units.tsv → 3129 unique gene tuples (428 duplicate groups, 637 TUs dropped). The promoter store grows from ~3283 to ~3766 unique molecules per chromosome copy — ~15% — and the transcript set shrinks back to the deduped ~3129–3283. Memory and per-tick cost impact is small.

8 · Risks and open questions

Upstream divergence. vEcoli keys everything by TU. AGENTS.md requires explicit justification; this qualifies, but it is the main cost and should be socialised before the work starts.

  • Variant-specific decay. The split asserts one decay rate per transcript. If 5′-variant-specific stability is ever measured, the model needs an extension point — design one rather than assume it never comes. leuLABCD's 289 nt 5′ spread is the case most likely to matter.
  • Translation. Ribosome binding depends on the 5′ UTR, and the split gives all variants one RBS. Already true today — translation is cistron-level with one efficiency per gene — so not a regression, but not fixed either.
  • get_motif_attributes currently derives promoters from TU coordinates. It needs a real TSS list; tu_to_thomason_match.tsv supplies matched positions for 594 TUs only, so unmatched promoters fall back to the TU's annotated start.
  • Division. chromosome_structure replicates promoters by np.repeat(…, 2); the promoter index must survive that and the daughter split.
